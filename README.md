# Civilization Clouds Simulator (CCS)

Исследовательская агентная симуляция возникновения цивилизаций на гексагональной карте.
Симуляция начинается не с городов и государств, а с «облаков» — ареалов расселения народов.
Из локальных правил роста, миграции, хозяйства и взаимодействия возникают смешанные культурные
области, сеть деревень и городов, государства и согласованные границы.

Подробные формулы и допущения — в [docs/MODEL.md](docs/MODEL.md).

## Запуск

```bash
npm install
npm run dev          # приложение: http://localhost:5173
npm test             # автоматические тесты (инварианты и сценарии)
npm run batch -- 10 exp   # серия из 10 запусков без визуализации, итог в batch-results-exp.json
npm run build        # проверка типов и сборка в dist/
```

Нужен Node.js 22+ (проверено на 24). Сервер и база данных не требуются.

## Интерфейс

* **Панель управления:** новая карта (seed или 🎲), запуск, пауза, следующий ход, +10, +50, сброс,
  скорость (ходов в секунду), сохранение и загрузка состояния (JSON).
* **Карта:** масштаб колесом и кнопками, перемещение перетаскиванием, подсказка при наведении,
  выбор гекса щелчком (в режиме облаков выбирается и облако), выделение клеток выбранного облака.
* **8 режимов карты:** география, культурные облака (цвет — облако, насыщенность — присутствие,
  точка — смешанная клетка), плотность, смешанный состав (круговые диаграммы культур),
  продовольственный баланс, поселения и зоны обслуживания, претензии (штриховка — спор),
  согласованные границы (нейтральные полосы, совместное использование).
* **Наблюдатель:** глобальный или конкретное среднее/большое облако — тогда неразведанное
  скрыто туманом, а сведения о других облаках ограничены знаниями выбранного. Переключение
  не влияет на симуляцию.
* **Вкладки:** гекс, облако (все параметры §14.5 и текущая стратегия с причинами), список облаков,
  журнал событий (фильтры, переход к гексу/облаку), решения ИИ (вклад факторов, отказы),
  статистика (9 графиков, табличный вид), отчёт, параметры (редактор всей конфигурации,
  сохранение/загрузка), эксперименты (серии в Web Worker, экспорт JSON).

## Структура

Логика симуляции полностью отделена от React и не импортирует ничего из интерфейса.

| Модуль ТЗ | Файлы |
|---|---|
| 1. Карта и география | `src/sim/mapgen.ts`, `noise.ts`, `hex.ts`, `geo.ts` |
| 2. Расы и культуры | `src/sim/culture.ts`, `config.ts` (расы, характеры) |
| 3. Население, рост, миграция | `pop.ts`, `demography.ts`, `migration.ts` |
| 4. Распространение облаков | `init.ts` (начальное размещение), `migration.ts` |
| 5. Характеры и ИИ | `ai.ts` |
| 6. Контакты, торговля, интеграция, конфликты | `interactions.ts`, `relations.ts` |
| 7–8. Нагрузка, сплочённость, гибридизация, расколы | `cohesion.ts`, `schism.ts` |
| 9. Продовольствие и транспорт | `food.ts` |
| 10. Поселения | `settlements.ts` |
| 11. Государства | `states.ts` |
| 12. Претензии и переговоры | `borders.ts`, `stability.ts` |
| 13. Управление ходами | `turn.ts`, `rng.ts`, `serialize.ts`, `batch.ts` |
| 14. Визуализация и аналитика | `src/ui/*`, `stats.ts`, `log.ts` |

Вспомогательные скрипты разработчика: `scripts/probe.ts` (сводка запуска),
`scripts/decisions.ts` (журнал решений заданного типа), `scripts/batch.ts` (серии).

## Тесты (`tests/`)

* `invariants.test.ts` — все 12 инвариантов §17.1 (неотрицательность, сохранение населения при
  миграции, интеграции и расколе, сосуществование культур, ограничения малых облаков,
  однократное использование избытка пищи, предел роста города, неизменность культуры при
  политическом присоединении, воспроизводимость, сохранение/загрузка).
* `scenarios.test.ts` — сценарии А–З §17.2.
* `knowledge.test.ts` — наблюдатель не влияет на симуляцию; агенты не идут в неразведанное.
* `batch.test.ts` — пакетные эксперименты, влияние параметров, сохранение конфигурации.

## Состояние по этапам

| Этап | Состояние |
|---|---|
| 1. География, облака, демография | готов |
| 2. Экономика и поселения | готов: иерархия деревня → городок → город, конкуренция зон, упадок |
| 3. Взаимодействия облаков | готов; расколы редки при параметрах по умолчанию (≈0.3 за запуск) |
| 4. Государственность и границы | готов; стабилизация до 300 хода — примерно в 40–50 % запусков |
| 5. Аналитика и эксперименты | готов |

Не реализовано (сознательно, по ТЗ или как упрощение): денежная экономика и отдельные
торговцы, армии и сражения, LLM-управление, архипелаги и несколько материков, передача знаний
о карте между союзниками.
